# Messenger links → Better Messenger

Chrome-расширение: ссылки `https://messenger.360.yandex.ru/#/chats/...`, открытые в браузере, открываются в десктопном Yandex Messenger через Better Messenger, а не в Телемосте.

## Установка

1. `chrome://extensions` → включить **Developer mode** → **Load unpacked** → выбрать эту папку.
2. При первом клике по ссылке Chrome спросит, открыть ли Better Messenger. Отметь «Всегда разрешать» — дальше ссылки будут открываться без вопроса.

Нужен [Better Messenger](https://github.com/viktoraseev/yandex-messenger-better-messenger) версии 0.4.0 или новее. Начиная с этой версии он обрабатывает схему `better-messenger://`.

## Как работает

1. Расширение срабатывает на `messenger.360.yandex.ru` до любых скриптов страницы. Если в адресе `#/chats/...`, оно останавливает загрузку страницы. Веб-приложение не стартует и на Телемост не уводит.
2. Затем расширение меняет схему ссылки — `https:` на `better-messenger:` — так же, как раньше веб-версия делала с `ychat:`.
3. Better Messenger, если нужно, запускает Messenger со своей инъекцией и передаёт ему ссылку как `ychat://messenger.360.yandex.ru/#/chats/...`. Схему `ychat` регистрирует Yandex Messenger.app. Ссылка попадает в уже запущенный экземпляр, второй процесс не стартует.

## Ограничения

- Обрабатываются только ссылки на чаты (`#/chats/...`). Остальные страницы messenger.360.yandex.ru расширение не трогает.
- Вкладка с заглушкой остаётся открытой. Если её закрыть сразу, пропадёт диалог Chrome «Открыть приложение?».
